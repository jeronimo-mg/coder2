# Product Definition: Coderagy

## Initial Concept
A CLI tool similar to Gemini CLI/Antigravity CLI, capable of generating code using the `antigravity-preview-05-2026` agent. Supports sandbox persistence, Gemini CLI extensions (like Conductor), and code downloading from sandbox environments.

## User Persona
Software Engineers, AI Researchers, and CLI Power Users who need a robust, agent-driven coding environment.

## Key Features
- **Sandbox Persistence:** Reusable Linux sandbox environments for ongoing agent work. Persistent state is stored locally within the project directory for seamless resumption of tasks.
- **Extension Support:** Full compatibility with Gemini CLI extensions.
- **Advanced Code Handling:** Secure and reliable extraction/download of code from sandboxed environments.
- **Agent Orchestration:** Integration with `antigravity` agents.

## MVP Scope
Feature-rich MVP including all core capabilities.

## Interface
Traditional CLI.
