# Product Definition: Coderagy

## Initial Concept
A CLI tool similar to Gemini CLI/Antigravity CLI, capable of generating code using the `antigravity-preview-05-2026` agent. Supports sandbox persistence, Antigravity/Gemini CLI plugins and extensions (like Conductor Plugin and DesktopCommander), and code downloading from sandbox environments.

## User Persona
Software Engineers, AI Researchers, and CLI Power Users who need a robust, agent-driven coding environment.

## Key Features
- **Sandbox Persistence:** Reusable Linux sandbox environments for ongoing agent work. Persistent state is stored locally within the project directory for seamless resumption of tasks.
- **Plugin & Extension Support:** Compatibility with Gemini CLI extensions and Antigravity plugins (such as Conductor Plugin).
- **Advanced Code Handling:** Secure and reliable extraction/download of code from sandboxed environments.
- **Agent Orchestration:** Integration with `antigravity` agents with conversational Spec-Driven Development.

## MVP Scope
Feature-rich MVP including all core capabilities.

## Interface
Traditional CLI.
