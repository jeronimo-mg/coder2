# Track: Conductor Integration

## Goal
Integrate the 'conductor' Gemini CLI extension into Coderagy to enable context-driven development.

## Plan
1. Research Conductor CLI requirements and API.
2. Update `main.py` to add a `conductor` command.
3. Create a wrapper or interface in `mcp_manager.py` or a new module to interact with Conductor.
4. Integrate Conductor functionality into the interactive TUI.
