A ideia é criar um código/script/software/app (vamos chama-lo de Coderagy) similar a Gemini CLI e/ou Antigravity CLI, capaz de gerar/criar código usando o agente antigravity-preview-05-2026 (veja @agy.py). Este agente trabalha em um ambiente sandbox Linux, então o Coderagy tem que ser capaz de fazer o download do código gerado/criado (veja https://ai.google.dev/gemini-api/docs/agent-environment). Além disso, ao ser reaberto, o Coderagy tem que apresentar a possibilidade de reutilizar um sandbox Linux utilizado anteriormente (veja https://ai.google.dev/gemini-api/docs/antigravity-agent). Também tem que ser capaz de usar extensões e plugins do gemini cli e antigravity, como o plugin conductor (veja https://developers.googleblog.com/evolving-spec-driven-development-conductor-now-supports-antigravity/ e comando agy plugins install https://github.com/gemini-cli-extensions/conductor) e desktop-commander (gemini extensions install https://github.com/wonderwhy-er/DesktopCommanderMCP).
